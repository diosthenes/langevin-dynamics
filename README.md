# langevin-dynamics
This code aims to simulate the dynamics of a particle governed by the Langevin equation, in the presence of an external force, temperature gradients, and such. The numerical integration is done by varying methods, including Euler-Maruyama, Milstein. The obtained particle density at the end of the simulation run is then compared against the Probability density predicted by the Fokker-Planck equation, and checked whether the results agree.
# physical parameters
The code was simulated for n number of particles mimicking real physical conditions. An ensemble of n mesoscopic particles in water were taken. A smooth potential was taken, which had two potential wells separated by a plateau region. Additionally, a linear temperature ramp was set-up between the wells, along the plateau region.
